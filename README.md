# Моніторинг законопроєктів Верховної Ради

Telegram-бот перевіряє офіційний розділ ВРУ [«Надходження законопроєктів за період»](https://itd.rada.gov.ua/billinfo/Bills/Period), відкриває картки законопроєктів, відкидає частину процедурних ініціатив і публікує короткі дописи з датою реєстрації, авторами, їхніми фракціями/партіями, суттю та стислим аналізом.

## Налаштування GitHub Secrets

У репозиторії відкрий **Settings → Secrets and variables → Actions** і додай:

- `TELEGRAM_TOKEN` — токен бота від BotFather.
- `CHANNEL_ID` — ID каналу або `@username` каналу. Бот має бути адміністратором із правом публікації.
- `OPENROUTER_API_KEY` — ключ OpenRouter для аналізу законопроєктів.

За потреби можна задати змінну репозиторію `OPENROUTER_MODEL`; стандартна модель — `openai/gpt-4o-mini`. Переконайся, що ця модель доступна для твого акаунта OpenRouter. Без API-ключа бот працює в резервному режимі без генеративної моделі.

## Увімкнення та вимкнення моніторингу

Перемикач працює через змінну репозиторію **`MONITORING_ENABLED`**:
- **`true`** — моніторинг увімкнений.
- **`false`** — запуски за розкладом пропускаються.
- Якщо змінну ще не створено, моніторинг увімкнений за замовчуванням.

Щоб змінити режим, відкрий **Settings → Secrets and variables → Actions → Variables → New repository variable** (або натисни Edit для вже створеної змінної), задай ім'я `MONITORING_ENABLED` і значення `true` чи `false`. Зміна діє для наступного запуску workflow. Щоб перевірити негайно, відкрий Actions і запусти workflow вручну після перемикання.

## Запуск

- Workflow `.github/workflows/run_bot.yml` запускає перевірку кожні 30 хвилин і підтримує ручний запуск через **Actions → Моніторинг ВРУ → Run workflow**.
- Наявний workflow налаштований на `self-hosted` runner. Він має бути встановлений, підключений до GitHub і доступний у момент запуску.
- `state.json` зберігає вже оброблені номери законопроєктів, підписників і кеш партійної/фракційної належності депутатів.
- Бот читає текст доступних PDF/DOCX-документів. Якщо офіційний портал не віддає текст документа або модель не може обґрунтувати аналіз, публікація може бути пропущена.
- Фракції/партії отримуються з поточних профілів депутатів на порталі ВРУ. Вони можуть відрізнятися від належності депутата на дату реєстрації законопроєкту.

## Формат допису

- Заголовок законопроєкту.
- Дата реєстрації та реєстраційний номер.
- Автори й офіційно вказані фракції/партії.
- Одне речення про суть.
- Аналітичний абзац до 80 слів.
- Посилання на офіційну картку.

## Обмеження відбору

Бот відкидає проєкти постанов та частину вузько процедурних ініціатив за назвою. Це початковий фільтр, а не повноцінна юридична експертиза: перед регулярним використанням варто переглянути перші публікації й уточнити правила відбору. Після додавання `OPENROUTER_API_KEY` модель отримує текст доступних супровідних документів і вирішує, чи достатньо матеріалів для обґрунтованого допису.
